# arvex — Instagram 運用方針

学生団体向け HP 制作事業の Instagram 運用方針。**決まったことのみ記載、陳腐化したら削除**。

## 1. 目的

複数目的を **重ね塗り** で同時達成する。並列チャネルには分けない。

| レイヤー | 目的 | 実装面 |
|---|---|---|
| 常時表示 (プロフィール / bio / ハイライト / 固定投稿) | 信用担保、能動 DM の下地 | 訪問者が 3 秒で「実在 / 実績あり / 怪しくない」と判断できる構成 |
| コア投稿 (実績ベース) | ポートフォリオ、思想発信 | 生成した `/p/[slug]` を素材に、団体紹介 + 設計意図を重ねる。1 投稿で両方処理 |
| CTA 層 (投稿末尾 + bio リンク) | 受動的リード獲得 | 「HP 無料提案中 → DM / bio リンク」を常設 |

**捨てるもの**: バズ狙いのミーム/リール、ノウハウ単品投稿 (情報垢化して信用が落ちるため)。POV は必ず実績投稿に寄生させる。

### 固定投稿 3 枠

プロフィール訪問者の最初の 3 秒を支配する面。実績ゼロ期でも成立する「Identity → Problem → Path」構成。

| 枠 | 役割 | 投稿内容 | カルーセル枚数 |
|---|---|---|---|
| [1] | Identity | **arvex マニフェスト** — 世界観、「テンプレじゃなくてデザイン」、誰のためか、何を大事にしているか | 5-7 |
| [2] | Problem | **なぜ HP が必要か** — SNS の限界 / HP の役割 (公式入口・信用・資産・空間) / HP 不在の機会損失。SNS は否定せず「両方あると強い」で締める | 7-10 |
| [3] | Path | **依頼の道筋** — フロー (DM → ヒアリング → 納品) / 料金 / 無料提案の仕組み | 5-7 |

**実績が貯まったら進化**:
- [1] マニフェストは変えない (事業の背骨)
- [2] を「実績ショーケース (代表作 3 選)」に差し替え、需要創出は通常投稿へ
- [3] は発注導線で固定

## 3. コンテンツ方針

3 本柱で回す。各柱が他の柱を強化する相互補強の三角形:

```
       [ 思想 / POV ]
         /        \
        /          \
  [ 需要創出 ] ─ [ 実績 ]
```

| 柱 | 役割 | 三角形内の役割 |
|---|---|---|
| **実績ケーススタディ** | 信用担保 / ポートフォリオ / "物" の層 | 思想を具現化、需要創出の着地点 |
| **思想 / POV** | arvex の世界観 / editorial identity | 実績に意味を与え、需要創出の背景を作る |
| **需要創出 (なぜ HP が必要か)** | 市場そのものを立ち上げる / ファネル最上流 | 実績へ着地、思想と連結 |

**他の投稿型はこの 3 柱に吸収する**:
- FAQ / 料金 / 依頼フロー → 実績 or 需要創出のキャプション、ハイライト常設
- タイミング連動 (新歓 / 学祭 / 引継ぎ期) → 需要創出の発動条件
- ソーシャルプルーフ (利用団体の声 / 反応) → 実績の補強
- リール / 動画 / インフォグラフィック → 3 柱の表現形式 (format であって柱ではない)

**発注訴求 (料金表 / フロー / CTA) はフィードの柱にしない**。bio / ハイライト / 各投稿末尾の常設 CTA に集約する。フィード本体が売り込み色になると B/C の思想的な信用が溶ける。

**禁句**:
- 「AI が作ってます」「自動で生成」系の言及 (事業全体の方針)
- 脅しマーケ (「HP 無いと損します」)
- 上から目線 (学生団体を "わかってない人" として扱う構図)
