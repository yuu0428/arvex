## 総評（arvex の設計基準として）

### 観察されるパターン

- **URL が linktr.ee / note / Instagram に集中している**団体が多い。独自ドメイン HP を持たない事が普通
- 独自 HP を持つ団体も Jimdo / Wix / Strikingly / peraichi / amebaownd の**無料ノーコード**が圧倒的。壊れやすい
- Web として素晴らしいデザインの独自 HP は**NPO カタリバ**（https://www.katariba.or.jp/）くらい。有力大手のみ
- 学生サークル級は**情報が載ってれば十分**、デザイン凝り度は低い

### arvex のポジショニング

- 「デザインがプロレベルで、情報がちゃんと載る独自ドメイン HP」= 既存に**ほぼ存在しない**層
- これを安価に提供できれば差別化可能
- ただし**Jimdo の HP がある団体**に対しては「お金払う価値あるの？」の壁がある
- **linktree / note しか持たない団体**が第一ターゲット

### 参考にすべきデザイン水準

- NPO カタリバ（https://www.katariba.or.jp/）が事実上の国内ベンチマーク
- 海外まで含めるなら: Teach For America、charity: water、The Trevor Project 等
- **「シンプル、写真多め、明確な CTA、実活動が見える」**が共通項
