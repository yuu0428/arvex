# 関西大学演劇研究部『学園座』
- URL: https://gakuenza.jimdofree.com/
- 参考カテゴリ: E (演劇・パフォーマンス)

## 観察したデザイン特徴
- Jimdo の無料テンプレに公演ビジュアルを差し替えた質素な構成（visual は凝らず、公演チラシ画像そのものが主役）
- トップに直近公演チラシ、下に「お知らせ」リストという典型的な部活HP構造
- ナビは「TOP / 公演情報 / 公演履歴 / 部員紹介 / お問い合わせ / アクセス」の6項目に絞ったシンプル設計
- 1946年創部・78年目という歴史を数字で見せるが、UIは現代風に寄せない
- SNS（X・Instagram・YouTube）への導線が目立ち、HPは"入口"的な役割

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 1946年創部、部員60人超の関西大学で最大の演劇研究部です。「お客様も自分たちも楽しむ」をモットーに、年5回の公演を誠之館BOXと小ホール、KUシンフォニーホールでやっています。ジャンルは縛らず、新人公演から卒業公演まで色々やります。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 関大に入ったばかりの1回生で、「演劇ちょっと気になるけど、サークルどこ入ろう」と迷っている子。あと、OBOG、保護者、近所で公演ポスター見て気になった人。メインは新歓期の新入生です。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 「次の公演観に行ってみよう」か「新歓行ってみよう」のどちらか。最低限、直近公演の日時と場所が頭に残ればOK。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 78年の歴史と、関大で最大という部員数です。新人公演・夏公演・冬公演・卒業公演と年5回公演を回せるのはこの規模じゃないと無理。あとKUシンフォニーホールが使えるのは関大の部活だからこそ。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 直近公演のチラシをドーンと。新人公演『有毒少年』（末満健一脚本）みたいに脚本家の名前が立つ公演ならそこも強調したい。キャッチコピーは要らない、チラシで語る。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. チラシのデザインが毎回違うので、HP側はそれを邪魔しない白ベース＋黒文字がいい。避けたいのは「アングラ演劇感」「暗い内輪ノリ」。うちはエンタメ寄りで、初めての人にも入りやすい雰囲気にしたい。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 公演予約（Google Form か外部予約ページ）と、DM への導線。新歓期は「部員紹介」ページと SNS フォローが最優先。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 関西の大学演劇サークルは Wix の凝ったサイトを作りがちだけど、うちは公演数が多いので更新しやすさ優先で Jimdo。凝るより、毎公演ちゃんとチラシを差し替えて運用されてる感を出したい。

### Q9. "これがないとウチじゃない"という要素は？
A9. 公演履歴ページ。78年分の公演タイトルが並んでるのは学園座にしかできない説得力。あと部員紹介の顔写真、規模感が伝わる。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 部員が代々更新するので10年以上。執行代が変わっても触れるように、Jimdo の素直なテンプレで。CMS 的な凝り方はしない。
