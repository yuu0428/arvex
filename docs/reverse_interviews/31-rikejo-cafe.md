# 理系女子未来創造プロジェクト（RIKEJO CAFE）
- URL: https://rikejocafe.jp/
- 参考カテゴリ: B（就職・キャリア系に寄りつつ、学生団体ディレクトリ要素のある D/F 混合）

## 観察したデザイン特徴
- 白ベース + 読みやすいゴシック体、企業ロゴが整然と並ぶ「カタログ型」レイアウト
- Nissan / Microsoft / Siemens / INPEX など 40 社超のパートナーロゴを面で見せる構成
- 「会員登録（無料）」と「人事 採用担当者の方」の 2 系統 CTA が同格で並ぶ B2B2C 設計
- コンテンツは記事・コラム・インタビュー中心で、装飾より"情報量で信頼を作る"方向

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 理系女子（大学の理工系に進んだ女子学生）と、理系女性を採用したい企業をつなぐ web メディアです。キャリア記事と企業インタビューと、会員限定のインターン情報を運営しています。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 二方向あります。一つは理工系の学部 2〜3 年生で、研究室選びとキャリアの接続に迷っている女子学生。もう一つは理系女性を採りたい企業の人事。だから読者ビューと採用担当ビューを両方用意してほしいです。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 学生は「会員登録して記事とインターン情報を取りに来る」。企業側は「ここに出稿すれば理系女子にリーチできる媒体だ」と認識する。その 2 つのアクションが同時に起きる構造にしたいです。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 40 社以上の企業と直接パートナーシップを組んでいて、Nissan・Microsoft・Siemens・INPEX といった名前が並ぶこと。個人の発信ではここまでの企業ロゴの厚みは出せません。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「理系女子の、未来を創るプラットフォーム」というような言い切り。写真より、協賛企業のロゴ壁を見せたい。学生にも企業にも"規模"で信頼してもらう必要があるので。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 清潔・誠実・採用広報でも使える品格。ピンク×ハートの"女子向け"テンプレは絶対に避けたい。理工系の女子は、そこに一番冷める層です。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 学生の無料会員登録。登録者リストがそのまま企業への提案材料になるので、ここが全ての起点です。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. よくある「女子学生コミュニティ」より、企業側の入り口を堂々と出している点。採用メディアとして成立していることを見せる。

### Q9. "これがないとウチじゃない"という要素は？
A9. 企業インタビュー記事と、そこから繋がるインターン導線。理系女子の"先輩の声"と"現場の写真"がないとただのディレクトリになります。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 媒体としての寿命は長く。年次更新で記事と企業ロゴを入れ替えていく想定。3〜5 年スパンで使う前提の設計です。
