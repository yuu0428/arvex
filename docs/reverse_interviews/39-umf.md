# 学生団体UMF（University Music Festa）
- URL: http://gakuseidantaiumf.wixsite.com/gakuseiumf
- 参考カテゴリ: D（イベント・フェス系、音楽） / E（メディア混合）

## 観察したデザイン特徴
- Wix ベース、ネイビー〜ブルーのロゴカラーを基調にしたプロフェッショナル寄りの外観
- HOME / ABOUT / EVENT / GALLERY / SPONSORSHIP / CONTACT の 6 固定ナビ
- 協賛企業ロゴと協力団体ロゴを「壁」にして並べるのが最大のビジュアル武器
- SNS 4 媒体（FB / X / IG / YouTube）アイコンがヘッダーに常駐、露出面の広さを誇示

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 学生によるフェス情報メディア「ongacu（オンガク）」の運営と、実際のフェス「University Music Festa」開催を同時にやっている団体です。関西・大阪拠点。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 3 層。フェス来場してくれる学生／協賛契約してくれるエンタメ業界の企業／運営に入りたい新入生。特に協賛導線は商売上の最優先。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. チケット購入、または協賛問い合わせフォーム送信。Ongacu 記事閲覧で回遊してくれれば尚良し。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 学生団体でフェス主催 + 音楽 web メディア「ongacu」の二輪で運営していること。単発のイベント団体と違って年中回っている。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. フェス会場の観客ショット。その横に ongacu の記事サムネイルをカルーセルで。「聴く、観る、書く。ぜんぶ学生が。」

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. ブルー基調で"媒体としてのきちんと感"。協賛営業資料として渡せる水準。逆に、文化祭のポスターみたいな手書き感は避けたい。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 「SPONSORSHIP お問い合わせ」。フェス運営資金はここに依存するので、ナビ上に独立項目として置いている。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. フェスだけの団体ではなく、記事・動画・フェスの 3 メディアを縦断している"ミニ音楽メディアハウス"であること。

### Q9. "これがないとウチじゃない"という要素は？
A9. 協賛企業ロゴの壁。学生団体でここまでの協賛網を出せるところは少ない。あと ongacu のロゴ。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. フェスは年次、サイトは 3 年スパン。代表交代後も運用しやすいよう、Wix で編集できる構成を維持したい。
