# Nativ.media
- URL: https://nativ.media/
- 参考カテゴリ: A (地域活性化・メディア系 / 移住特化)

## 観察したデザイン特徴
- 白背景＋カードレイアウト、記事サムネとメタ情報がクリーンに並ぶ
- ナビが4軸（地方移住／関係人口／地方求人／イベント・セミナー）＝目的ファーストの導線
- NEW TOPICS / FEATURES / Nativ.チャンネル / EVENT のセクション分け
- 「Nativ.」と末尾にピリオドを含むロゴ。編集メディアらしい冷静なタイポ
- 写真は移住成功者の人物カットが多く、"体験談"を前面に

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 地方移住と関係人口創出にフォーカスしたWebメディアです。移住した人の実話、地方求人、移住セミナーの情報を一箇所に集めて、「地方に関わりたい人」と「迎えたい地方」のマッチングを支えます。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 30〜40代の共働き夫婦、都市部で消耗している若手、Uターン検討中の地方出身者。もう一方の軸で、地方求人を出したい自治体・中小企業。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 移住セミナーに申し込むか、求人に応募するか、関係人口プログラムにエントリーするか、最低限メルマガに登録してくれること。「読んで終わり」で帰さない。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 「移住」だけでなく「関係人口」を同格で扱っていること。いきなり移住はハードルが高い人のために、中間段階（二拠点・副業）の情報と求人を並べて見せられる。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 実際に移住した人の顔写真と、その人のひとことコピー。概念ではなく「この人も実在する」という証拠を顔に。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 清潔で落ち着いた編集メディアの型。避けたいのは地方自治体パンフレットの堅さと、移住ポータルサイトの情報羅列感。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. イベント／セミナーの申込、求人への応募。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 移住メディア単体ではなく「求人」「関係人口」「セミナー」が一つのナビに同居している**ハブ型**である点。

### Q9. "これがないとウチじゃない"という要素は？
A9. 「関係人口」カテゴリの独立と、Nativ.チャンネルの連載。ロゴのピリオドもブランドの記号。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 5〜10年。移住ニーズは長期トレンドなので、資産になるフレームで作る。
