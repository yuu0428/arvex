# 起業スタートダッシュ（東京都・高校生起業家養成）
- URL: https://kstartdash.metro.tokyo.lg.jp/
- 参考カテゴリ: C（行政運営の起業家育成プログラム）

## 観察したデザイン特徴
- 東京都（metro.tokyo.lg.jp）公式ドメインの行政サイトだが、通常の役所ページと違いキャンペーン LP に近い構成
- 白 + 東京都ブランドの青ロゴ、クリーン San-Serif、見出しの階層が整理されている
- ヒーローは横スライダー（主要告知を順送り）+ 3 段階プログラムの 3 カラム（Kickoff → Training → Acceleration）
- 「On your Mark → Get set → Start!」の陸上スタートメタファーがプログラム全体を貫く
- 高校生の候補写真（上を見上げる / 笑顔 / アクション系）を多用 = 行政サイトにしてはカジュアルで明るい
- 「ワクワク」「未知の視座」など感情語を混ぜ、行政の硬さを中和
- Instagram / Facebook 連携、教員向け資料ダウンロード、スキップリンク（アクセシビリティ対応）完備
- 生徒本人 + 保護者 + 教員という 3 読者層を同じページで捌いている

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 東京都が運営する、高校生専用の起業家養成プログラムです。Kickoff（気づき）→ Training（学び）→ Acceleration（実行）の 3 段階で、大学生向けではなく高校 1-3 年生に特化しています。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 本命は「東京都内の高校 1-2 年生で、進路を大学進学一択に決めきれず違う選択肢を探している子」。次に、申込手続きを代行する保護者と、生徒にチラシを配る高校の進路指導教員。3 者同じページで読む前提です。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 生徒本人には「エントリーフォームから応募」。保護者には「東京都の公式事業だから安心」と納得してもらう。教員には「校内で紹介用資料をダウンロードしてもらう」。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 東京都が税金でやっているので参加費が無料または超低廉で、しかも現役起業家・VC・大学教員がメンターにつく規模感は民間のスタートアップスクールでは真似できません。高校生だけ、という絞り込みも強みです。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「高校生のうちに、未来を動かす経験を。」のコピー。写真は制服を着た高校生がピッチステージで指を立てている、または登校前の空を見上げている瞬間。顔の表情で未来感を出す。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 大事：白 + 東京都ブルー、キャンディ色のアクセント、丸みのある San-Serif、高校生の実写。避けたい：硬すぎる官庁 PDF 調、逆に派手すぎる商業 LP 調。「都の事業だから信頼できる」と「高校生が読める柔らかさ」の中間。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 「プログラム参加エントリー」が最上位。次点で「学校向け資料ダウンロード」と「イベント申込」。申込期間外は過去インタビュー記事を読ませる構造で滞留させる。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 民間の起業塾（Startup Weekend 高校生 / Entre-in 等）と並んだとき、「東京都公式」という信頼と「完全無料 / 低額」の強みを前面に。同時に、役所の他ページより圧倒的にデザインがいいという見た目で、高校生に「こっちは違う」と思わせたい。

### Q9. "これがないとウチじゃない"という要素は？
A9. 東京都ロゴ、metro.tokyo.lg.jp ドメインの信頼、3 段階プログラム図、「On your Mark → Get set → Start!」のスタートメタファー、教員向け資料導線（学校配布を前提にしている証）。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 事業の予算が単年度ごとに組まれるので、年度ごとに募集要項・日程・メンター一覧が差し替わる前提。骨格は 3 年持たせたいが、毎年 3 月にコンテンツ更新が入る CMS 構成必須。アクセシビリティ JIS X 8341-3 準拠は恒久維持。
