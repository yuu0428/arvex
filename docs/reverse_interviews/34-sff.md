# Student Freepaper Forum
- URL: https://sff-web.com/
- 参考カテゴリ: D（イベント・フェス系） / E（紙メディア・出版寄り）

※ sff-web.com は 2026/04 時点でドメイン売却済み。以下は公式 Ameba Ownd（sff.themedia.jp）と PRTIMES/各種紹介記事からの逆算。

## 観察したデザイン特徴
- ミニマルな横ナビ、About / Store / 活動概要 / YouTube の 4 軸構成
- 「お待ちしております…！」系の柔らかい招待コピー、学生手作り感を残したトーン
- 全国 100 団体超・来場 1000 人超という"数"が実績の核
- 2006 年開始 → 2014 年にコンテストからフェス形式へ転換、という歴史の軸

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 全国の学生フリーペーパーが年 1 回 12 月に集まる日本最大のフリーペーパーの祭典「Student Freepaper Forum」を運営する学生団体です。合言葉は「学生フリーペーパーを文化に」。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 全国でフリーペーパーを作っている学生編集部と、その読者になってくれる一般来場者。あと新歓期は次世代の運営メンバー志望者。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 参加団体としてエントリーする／12 月のフォーラムに来場する／運営メンバーに応募する。この 3 択のどれかまで進んでほしい。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 2006 年から続く、全国 100 団体・1000 人が集まる学生フリーペーパーの"唯一の祭典"であること。2014 年にコンテスト制をやめてフェス化した、その判断も含めてウチの物語。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「学生フリーペーパーを文化に」。その下に、過去フォーラムで並ぶフリペの机の写真。紙がテーブルに並んでいる光景が"SFF らしさ"です。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 紙の質感、インクの匂いがしそうなトーン。テカテカしたデジタル感は要らない。ただし古くさくもしたくない、学生の"今"の紙文化なので。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 出展団体エントリーと、新入運営スタッフ募集。年末のフォーラム告知期は「来場申込」に切り替わります。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 「コンテスト」ではなく「フェス」であること。順位をつけない、集まることが目的の場だと明示したい。

### Q9. "これがないとウチじゃない"という要素は？
A9. 参加団体ロゴ（表紙）の壁。100 誌並ぶあれがないと規模感が伝わらない。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 年次更新。回次情報部分だけ差し替えて長く使う前提。骨格は 3 年は持たせたい。
