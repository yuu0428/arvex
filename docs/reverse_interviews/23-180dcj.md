# 180 Degrees Consulting Japan（東京支部）
- URL: http://180dcj.wixsite.com/tokyo
- 参考カテゴリ: C（ビジネス・起業系 / 学生コンサルティング）

## 観察したデザイン特徴
- 現状は新サイト（180dctokyo.studio.site）への redirect ページ。Wix 公式のお知らせテンプレで、ロゴ + 中央告知 + ボタン 1 つのミニマル構成
- 本体（新サイト）は STUDIO 製のモダンなモノクロ+アクセントカラー設計が想定される
- 「世界最大の非営利コンサル学生団体 日本支部」という英語圏ブランドの翻訳版なので、180DC 本部のグローバル CI（白黒 + 鮮やかな赤または黄）に準拠しているはず
- フォーマル、丁寧語、英語併記される前提。学生ノリより事業者寄りのトーン
- 対クライアント（NPO/NGO）と対学生メンバーの 2 面性を 1 枚で解くサイト

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 世界最大の非営利コンサルティング学生団体「180 Degrees Consulting」の東京支部です。ソーシャルセクター（NPO / 社会的企業 / NGO）に対して、学生メンバーが無償または低額でコンサルティング・プロジェクトを提供します。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 二つあります。一つは「コンサル経験を積みたい東大・一橋・早慶の学部 2-3 年生」、もう一つは「マーケや組織設計で行き詰まっていて、予算が無いからコンサルを雇えない NPO 代表」。この 2 者に同じページで響かせる必要があります。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 学生には「次の採用エントリーに応募」、クライアント候補には「プロジェクト相談フォーム送信」。そして「180DC は世界 100 支部以上ある本物のネットワークだ」と理解してもらう。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 180DC グローバルの方法論とケースライブラリが使えることです。他の学生コンサルと違い、ロンドン本部のガイドラインに沿ったフレームワーク運用ができる。あと OB / OG が MBB・BIG4 に多数進んでいて、プロジェクトのレビューに入ってくれます。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「Consulting, for good.」のような英語コピー。写真はプロジェクトでクライアントに提案している瞬間のミーティング風景。スーツではなく、ビジカジで紙資料を広げている絵。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 大事：モノクロ基調 + 180DC のシグネチャーカラー、San-Serif 英文フォント、余白、英語併記。避けたい：アニメ絵・学園祭ノリ・「ガクチカ」臭。他の学生団体より「プロのコンサルファーム」寄せでいきたい。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 期別で変わります。採用期は「メンバー応募」、それ以外は「プロジェクト相談（クライアント向け）」。現在は旧サイトから新サイトへの誘導そのものが最優先。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 国内の学生コンサル団体（ICC / CROP とか）とは差別化したい。うちは「世界 100 以上の支部の 1 つ」という国際ネットワークが武器なので、Global / Network / Evidence-based の 3 ワードを強調。

### Q9. "これがないとウチじゃない"という要素は？
A9. 180DC グローバルロゴと「Japan chapter」という位置付けの明示。そして過去クライアントのロゴウォール（NPO や社会的企業の実名）。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 今まさに Wix → STUDIO 移行中なので、新サイトは 3-4 年の想定。代替わりごとにメンバー紹介だけ差し替えられる構造が必須です。
