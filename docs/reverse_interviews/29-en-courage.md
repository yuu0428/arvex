# en-courage（エンカレッジ）
- URL: https://en-courage.com/ （現在 app.en-courage.com へ 301 リダイレクト）
- 参考カテゴリ: C（就活支援 / メガプラットフォーム）

## 観察したデザイン特徴
- ブルー（コーポレート寄りの落ち着いた青）アクセント、モダン San-Serif、カード UI 中心のプラットフォーム型 UI
- ヒーローで 2 サービス（「mikketa」スカウト / 「Career Leverage」特別スカウト）を並列
- 「累計登録 30 万人突破」を序盤で強調 = 社会的証明先行型
- Top 10 ランキング → イベント一覧 → 企業ショーケース → カテゴリフィルタ の流れで、コンテンツ量で圧倒
- 「締切直前」「差がつく」「内定」など就活特有の煽り語彙
- 新卒 27-28 卒向け。メンター面談・インターン・セミナー・合説が混在
- Web サイトというより SaaS ダッシュボード（`app.en-courage.com`）に統合されたログイン型サービス

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 累計 30 万人が登録する日本最大級の就活支援プラットフォームです。もともと東大発の OB/OG 面談の学生団体として始まり、今は株式会社化してメンター面談・スカウト・セミナーを統合提供しています。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 一番は「27 卒・28 卒の大学 2-3 年生で、就活に出遅れたくない人」。サマーインターンのエントリー前に登録してほしい。次に、優秀層にスカウトを送りたい採用担当者。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 学生には「無料会員登録」、企業には「mikketa / Career Leverage への導入相談」。イベント単発申込より、アカウント登録して滞留してもらうことが最優先。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 累計 30 万人のデータベースと、全国 OB/OG メンターネットワーク。他の就活サービスは「企業 → 学生」の一方向ですが、うちは先輩学生からの 1on1 面談が軸で、これは en-courage の原点であり模倣されにくい。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「差がつく就活は、出会いから。」のような一言と、30 万人・メンター◯万人の数字。写真よりも数字とロジックで押したい。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 大事：信頼の青、白基調、カード UI、数字の視覚化。避けたい：原色ポップ、学生団体ノリ、手書き風。en-courage は今や上場企業並みの採用商材なので、学生サークル感は完全に剥がしたい。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 「無料会員登録」が最上位 CTA、次が各イベントの「申込」。メンター面談予約もフック CTA として散りばめる。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. ONE CAREER / ワンキャリア / マイナビと並んだとき、en-courage は「先輩との 1on1 面談」という人的接触を最前面に出したい。就活情報サイトではなく「メンターマッチングプラットフォーム」。

### Q9. "これがないとウチじゃない"という要素は？
A9. 累計登録者数 30 万人、メンター制度、東大発という出自、締切カウントダウン UI、そして app.en-courage.com へのシームレスなログイン導線。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. プラットフォームは継続運用前提で寿命という概念がない。半年ごとに機能追加・新卒年次更新が入るので、コンポーネントベースの CMS or 専用フロントエンド（Next.js）で持続運用。
