## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 関東の大学（東京都立大・横浜国大・埼玉大など）の学生が集まってハイブリッドロケットと CanSat を自作・打ち上げてるインカレサークル。秋田の能代宇宙イベント（8月）と伊豆大島共同打ち上げ実験（11月・3月）に出ます。独自開発エンジン CAMELLIA（2017年燃焼試験成功）→ LARKSPUR X → LARKSPUR XP と系譜があります。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 「宇宙・航空に興味あるけど、JAXAはまだ遠い」と思ってる関東圏の1-2年生。機電・情報系の学生。あとは Maker Faire などで CORE を知って詳細を調べたい外部の人。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 「新歓参加したい」「次の能代宇宙イベントでCORE見に行く」「ブログで進捗追う」。技術やりたい学生に "ここでロケットが作れる" と刺す。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 自作ハイブリッドエンジンを実際に燃焼試験まで持ってけること。CAMELLIA 2017→LARKSPUR と継承してる技術蓄積。あとインカレ構成なので複数大学の知見が合流する。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「大学には、ロケットを作るサークルがある」のコピーと、エンジン燃焼試験の発光写真。打ち上げ瞬間よりも、夜の燃焼試験のオレンジの炎の方が工学サークルらしい。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. ダーク背景、モノスペース系の数字表示、技術ドキュメント寄り。避けたいのは「サークル飲み会写真」「オタク同好会感」。NASA/JAXA の広報サイトくらいのトーンで。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 新歓応募フォーム（新歓期）。通年はブログ購読、Twitter フォロー、GitHub 確認。支援者向けに Maker Faire 出展案内も。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 他大の宇宙系サークル（北大・東工大など）は大学のサブドメに収まってるが、うちはインカレなので独自運営が必要。ブログ更新頻度と燃焼試験の写真で "動いてる感" を出す。

### Q9. "これがないとウチじゃない"という要素は？
A9. 独自エンジン命名系譜（CAMELLIA / LARKSPUR）、能代・伊豆大島の参加実績、年度別活動報告の積み重ね。どれも欠けたら "部活感" に落ちる。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. サークル自体が 2010 年代から続いてるので、HPも10年は運用。lolipop から netlify に移行中のように、ホスティングは時代に合わせて乗り換える前提。
