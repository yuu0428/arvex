# TRIGGER FES 実行委員会
- URL: http://triggerfes.jp/
- 参考カテゴリ: D（イベント・フェス系、音楽）

※ triggerfes.jp は 2026/04 時点で乗っ取り／音楽教室口コミサイトに転用済み。以下は公式 FB / Twitter / EYESCREAM / Spincoaster / 公式 ZINE（triggerfes.com）からの逆算。

## 観察したデザイン特徴
- 2011 年秋発足、「学生による、学生のための、学生の野外ロックフェス」を標榜
- 日比谷野音・渋谷 WWW など実会場の写真が主役、アーティストラインナップがビジュアルの核
- The Wisely Brothers / TENDOUJI / Gateballers などインディー〜アンダーグラウンド系を選ぶ審美眼
- 企画局（運営 + アーティスト渉外）/ 広報局 / 制作局の 3 部構成で、運営体制を公開している

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 関東の学生で構成される、野外ロックフェスと都内ライブハウスでのイベントを企画・運営する実行委員会です。2011 年に「学生による、学生のための、学生の」フェスを作ろうと立ち上がった。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 当日のチケットを買ってくれる 10〜20 代の音楽好き。それと、出演交渉する際に見せるアーティスト所属側（事務所・インディーレーベル）。信頼できる運営だと見せる必要があるので。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. チケット購入フォームまで進むか、出展アーティスト応募まで進む。アーティスト側は「ここに出て損はない」と判断する。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 日比谷野音で学生主催のロックフェスをやり切ったこと。TRIGGER FES 2013 SUMMER @日比谷野音、あれが一つの原点。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「未知の感性と出会うトリガーに」。団体名の由来でもあるキーワード。そして出演アーティストのラインナップ写真を一面に。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. ライブの熱と暗さ。キラキラ明るい学生イベント感は絶対 NG。黒地 + ネオン or 蛍光寄りの尖ったトーンを希望。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 次回開催日のチケット購入ボタン。閑散期は「実行委員募集」と「出演アーティスト応募」が並列。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 大学の軽音サークル系より「フェスを作る側」として立っていること。学校・学年不問であることも明示したい。

### Q9. "これがないとウチじゃない"という要素は？
A9. "TRIGGER"＝引き金、という言葉の重み。未知への入口を作っているという態度。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 回次ごとに上書き前提。次回フェスが決まったらメインビジュアルごと総入れ替え。骨格だけ 2〜3 年使う。
