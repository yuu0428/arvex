# 学生団体GEIL
- URL: http://waavgeil.jp/
- 参考カテゴリ: C（政策立案コンテスト学生団体）

## 観察したデザイン特徴
- HOME / ABOUT / EVENT / SUPPORTER / NEWS / CONTACT の水平ナビ、白背景基調のクリーンなレイアウト
- プレースホルダー画像が多く、ビジュアルの主役は「テキストと日付」= コンテスト運営サイトらしい硬派な構成
- 「1999 年から毎年、日本最大級の政策立案コンテストを学生向けに企画・運営」= 27 年目の実績
- 東大 / 一橋 / 早稲田 / 慶應 / 上智 のインカレ構成を前面に出している
- 2026 年現在は「Pre GEIL 2026」（4/18-19、2 日間）が直近 CTA で "参加受付中" を明示
- 協賛企業 / 官公庁向けに Annual Report セクションが独立で存在
- Twitter / Instagram / Facebook / LinkedIn の 4 ソーシャル（LinkedIn がある = 対社会人意識）
- ドメイン `waavgeil.jp` で WAAV（KING / OVAL との姉妹ブランド）を継承

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 1999 年から続く、日本最大級の政策立案コンテストを運営している学生団体です。ビジネスコンテストと違って「政策」を立案する。社会課題をテーマにして、毎年夏に本戦を開きます。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 一番は「政策 / 公共政策 / 官僚志望の大学 1-3 年生」。東大公共政策・一橋社会・早稲田政経・慶應 SFC・上智総合政策が主な送客元。次に、協賛を検討する官公庁・シンクタンク・コンサル。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 参加者候補には「Pre GEIL か本戦にエントリー」、協賛候補には「Annual Report を請求する」。そして「ビジコンじゃなくて政策立案」という差分を正しく理解してもらう。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 27 年間ぶれずに「政策立案」一本で続けていることと、省庁・シンクタンクの現役職員がメンターとして本戦に張り付くこと。ビジコンと違って、提案が絵に描いた餅で終わらず、霞が関ロジックで殴られる緊張感があります。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「政策で、社会を動かす経験を。」というコピー。写真は本戦会場で役所の会議室風のテーブルを囲み、学生が資料を広げて議論している俯瞰写真。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 大事：白 + ネイビー or 濃紺、San-Serif でかっちり、余白多め、官庁パンフレット寄り。避けたい：チャラいグラデーション、ビジコン系の「ゴールド・王冠」演出。GEIL は堅実さが売り。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 時期で変わります。4-5 月は Pre GEIL 受付、6-7 月は本戦エントリー、8 月以降は Annual Report 請求と協賛問い合わせ。トップバナーが期別で差し替わる構造必須。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 姉妹団体 KING（ビジコン）・OVAL（国際）とトーンを揃えつつ、GEIL は「政策」という一点で硬派に寄せたい。KING が赤 / 黒の闘技場なら、GEIL はネイビー / 白の霞が関。

### Q9. "これがないとウチじゃない"という要素は？
A9. 27 年という数字、過去の歴代テーマ一覧（社会課題のアーカイブ）、Annual Report、省庁メンターの実名または所属ロゴ、WAAV 姉妹団体への相互リンク。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 代ごとに News と Pre GEIL / 本戦バナーだけ差し替わればよい作り。骨格は 4-5 年変えない前提。Annual Report の PDF 配布導線だけは落とさない。
