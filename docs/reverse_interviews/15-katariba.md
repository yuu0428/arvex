# 認定NPO法人カタリバ
- URL: https://www.katariba.or.jp/
- 参考カテゴリ: B (国際・ボランティア) / 教育・ユース支援

## 観察したデザイン特徴
- 白地に紺／濃紫のアクセントカラー、余白多めの上品なスペーシング
- 日本語はモダンなゴシック、見出しは大きめ・ウェイト重め、「未来は、つくれる。」的なスローガン型コピーを中央配置
- 子ども・ティーンエイジャーのポートレート／多様性を感じる集合写真を多用
- ナビは "活動を知る / 最新情報 / 寄付で応援 / 採用・インターン / お問い合わせ" と寄付・採用が明確に上位にある
- 複数個所に「寄付で応援」ボタン、SNS を5プラットフォーム並べる

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 10代が「ナナメの関係」の大人と出会って、自分の未来を自分で描けるようになる場所を、全国の学校・被災地・災害避難所・困窮家庭向けに作っています。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 最優先は月額寄付サポーター候補（30〜50代、教育に関心があり、少し余裕のある社会人）。次に採用候補（新卒・中途）、その次に連携したい学校・自治体の担当者。10代本人は SNS で別途取りに行くのでサイトの主役ではない。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 「カタリバは信頼できる規模感のある団体で、寄付は意味のある場所に届く」と腹落ちして、月々1000円でもクレカ登録するところまで行ってほしい。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 20年以上「ナナメの関係」という概念を作り育ててきたこと。学校教員でも親でもない第三の大人が10代の横に立つ、その設計図を全国で再現できるのはカタリバだけ。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「未来は、つくれる。」一枚は10代が何かに挑んでいる真剣な表情、もしくは大人と隣で対話している横顔。カメラ目線で笑わせない。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 上品さ・余白・落ち着いた色。避けたいのは「かわいそうな子どもを救ってください」的な同情ベースのトーン、派手な原色、顔の強い加工。信頼感と美意識の両立。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 「寄付で応援する」ボタン。特に月額継続寄付（サポーター会員）への誘導を最優先に。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 他の教育NPOが「子どもの課題」を前に出すのに対し、うちは「10代の可能性」を前に出す。赤字基調ではなく紺基調、悲壮感ではなく前向きさで違いを出す。

### Q9. "これがないとウチじゃない"という要素は？
A9. 「ナナメの関係」という自分たちで作った言葉。どのページにも必ず一度出てくる。寄付・採用・活動、すべてがこの言葉に束ねられる。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. リブランディング前提で 4〜5 年。認定NPOとしての格・ブランドの更新サイクルに合わせる。
