# NPO法人国際ボランティア学生協会 IVUSA
- URL: https://www.ivusa.com/
- 参考カテゴリ: B (国際・ボランティア)

## 観察したデザイン特徴
- WordPress ベースの大規模団体サイト（?page_id= 型の URL）。情報量が非常に多い
- 青・白基調でテキストは黒、写真は活動現場（清掃・祭り・災害救援・子ども支援）の実写が大量
- ナビが「IVUSAとは / 活動紹介 / ボランティアに参加する / 寄付 / 採用」とターゲット別に分岐
- トップで「5分野（国際協力・環境保護・地域活性化・災害救援・子どもの教育支援）」を横並びで見せる
- CTA は「参加する」と「寄付する」が同等の重さ

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 1993年設立、全国80大学・2,500〜2,700人の大学生が所属する日本最大級の学生ボランティアNPOで、国際協力・環境保護・地域活性化・災害救援・子どもの教育支援の5分野を同時並行で回しています。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 第一は新歓期の大学1年生。「サークル選びで "国際" と "ボランティア" を検索した子」が最初に来る。第二は寄付者・助成団体、第三は被災地自治体の災害救援依頼窓口。三つのオーディエンスをナビで分岐させる必要があります。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 学生には「最寄りのクラブ（28支部）の説明会に申し込む」、寄付者には「単発でもいいから振込む」、自治体には「電話していいんだと分かる」。一律の"読後感"ではなく三者三様の次アクションに落とす。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 災害発生から72時間で学生を現地に送り込める動員力と、それを30年続けている危機管理ノウハウ。民間NPOでここまで即応できるのは稀です。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「熱意は人を動かし、社会を動かす」。写真はヒーローを1枚に絞らず、5分野それぞれの現場カットをグリッドで並べて規模感を出したい。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 実際の活動現場の泥臭さ・汗が残る写真を優先。ストック写真は絶対に使わない。避けたいのは「綺麗すぎる国際協力サイト」、悲壮感で寄付を訴えるトーンもNG。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 「ボランティアに参加する」ページへの導線（新歓・各クラブ説明会）。寄付 CTA は常時出すけど優先度は二番目。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. JICA とか大手NPOは「プロの国際協力」の顔をする。うちは学生主体、ニュートラルな立場、学びの場でもあるという三つを前に出したい。「ボランティア＝奉仕」じゃなくて「ボランティア＝成長の場」。

### Q9. "これがないとウチじゃない"という要素は？
A9. 5分野を並列で見せること。どれか1つに絞った瞬間に IVUSA ではなくなる。あと、28クラブの一覧と各地の連絡先が必ず辿れること。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 骨格は 7-10 年。ただし新歓ページと災害速報ページは毎年/毎回更新するので CMS 運用前提。
