# 夢を叶えちゃうプロダクション『キャリー』
- URL: https://carry.amebaownd.com/
- 参考カテゴリ: F（クリエイター・制作集団系） / D 混合

## 観察したデザイン特徴
- Ameba Ownd の無料テンプレ、装飾を足さず余白とモノクロ寄りで"引き算"する構成
- 「昨日見た夢、覚えてる？」「あなたの欲張りなパラレルワールド」といった詩的コピーが"顔"
- デザイン / イベント / ゲーム / PR / 媒体運営（キコマシュ）の複数領域を横並びで見せる
- 所属は「高 1 から社会人 3 年目まで」と幅広く、学生サークル的デザインは避けている

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 立教大学発の、"夢を叶えちゃうプロダクション"です。デザイン・イベント・ゲーム開発・PR・web メディア「キコマシュ」運営を横断してやっている、学生主体の制作集団。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 何かを作りたいけど一人では踏み出せない高校生〜社会人数年目まで。もう一つは「若いチームに発注したい」クライアント企業です。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 「ここなら自分のやりたいことを置ける場所がある」と思って Twitter DM を送ってくる。お問い合わせは Twitter @CARRY_dreamers に一本化しています。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. web メディア「キコマシュ」を自分たちで回していること。作るだけでなく世に出す導線まで内製している学生団体はそう多くない。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「昨日見た夢、覚えてる？」。これを開口一番に置きたい。プロダクション名より先にこのコピーで掴みたいです。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 余白と静けさ。装飾でワイワイした学生サークル感は絶対に避けたい。"プロダクション"を名乗る以上、受注できる佇まいが要る。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. Twitter（@CARRY_dreamers）へのコンタクト。依頼・入会・取材すべてここに集約。メールフォームは作らない。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 学生団体の顔ではなく"小さなプロダクション"の顔で出すこと。年齢レンジを「高 1〜社会人 3 年目」と書いているのもそのため。

### Q9. "これがないとウチじゃない"という要素は？
A9. 夢を"叶えちゃう"の"ちゃう"。あの軽さが抜けると、ただの制作会社 HP になってしまう。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 2〜3 年。案件と媒体が変わったら刷新する前提。Ameba Ownd にしているのはその身軽さを優先したから。
