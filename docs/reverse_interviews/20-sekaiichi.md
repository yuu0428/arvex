# 世界市プロジェクト
- URL: http://sekaiichiweb.com
- 参考カテゴリ: A (地域活性化・メディア系) / グローバル文化メディア

## 観察したデザイン特徴
- 白基調にダーク（紺／黒）ナビ、カード型のグリッドで記事を並べる Web メディア型レイアウト
- 各記事に遅延読み込み画像、日付＋タイトル＋短い要約のシンプルなメタ
- カテゴリが「世界の街並紀行 / 文化 / インタビュー」、地域別（アジア／ヨーロッパ等）の二軸ナビ
- ページネーションありで、過去記事アーカイブが主役＝雑誌的構造
- CTA は記事詳細への誘導と「次のページ」。寄付・申込はない

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 「世界と日本の架け橋」を掲げて、学生を中心に世界各地の街並み・文化・人物インタビューを記事化して発信する、学生編集部型のウェブメディアです。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 海外旅行・異文化に興味がある20〜30代、特に「ガイドブックの情報じゃなくて同世代の目線で書かれた街レポート」を読みたい人。検索流入が多い想定。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 1記事読んだら、関連記事をもう2〜3本読んで、ブックマークに入れて、次に海外に行くときに参照する場所になってほしい。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 学生ライターが自分の足で行って書いている一次情報。商業メディアのようにPR案件も観光庁タイアップもない、完全に個人の視点で書かれた街のレポート。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「世界と日本の架け橋」。トップには「街の一枚」を大きく出すのが良い。人工的な観光地カットじゃなくて、朝のバザールとか夕方の路地とか、生活感のある一枚。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 大事なのは「旅雑誌っぽい余白」と「写真の発色」。避けたいのは旅行代理店の LP みたいな予約ボタンだらけの UI、あと Instagram のキラキラ旅行写真っぽいフィルター。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 記事を読み続けてもらう回遊。SEO流入のユーザーを滞在させ、複数記事読ませる。二次的にはライター応募とメルマガ登録。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. TABIPPO, TABIZINE, トリップノートみたいな商業旅メディアと差別化したい。うちは広告モデルじゃない、学生が書く、だから広く浅くじゃなく深く書ける。

### Q9. "これがないとウチじゃない"という要素は？
A9. 地域別の記事アーカイブ。「アジア」「ヨーロッパ」で深掘りできる分類。あと、著者名（学生ライター名）が記事ごとにちゃんと出ていること。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 7〜10年。記事が資産なので、デザイン改修で過去記事の URL を壊さないことが最優先。CMS は WordPress 継続で十分。
