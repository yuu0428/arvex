# 加子母木匠塾（かしももくしょうじゅく）
- URL: https://kashimoki.com/ （※ 2026/04 時点で fetch 失敗。現行公式は https://www.kashimokusho.com/ の模様。以下はそちらと団体情報から観察）
- 参考カテゴリ: A (地域活性化・メディア系) + 建築学生コミュニティ

## 観察したデザイン特徴
- ヒノキの色を想起させるベージュ・茶系の落ち着いた配色、サンセリフ＋明朝寄りの見出し
- 「全国から学生が集まり、加子母で木を学ぶ」という地名＋素材のキャッチがトップ
- ナビは「沿革 / 活動・事業内容 / 制作物 / 同窓会 / リンク集」と時間軸と成果物で整理されている
- 年度ごとの制作物アーカイブが目次的に並ぶ＝資料性が高い
- CTA は SNS と同窓会入会、オンラインショップ、問い合わせメール

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 岐阜県中津川市加子母に全国8大学の建築学生が集まって、東濃ヒノキの産地で地元の大工さんと一緒に木造建築を実地で作る夏の合宿、それが30年続いています。大学では学べない継手・仕口をここで覚えます。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 第一に建築学科の1〜2年生で「設計だけじゃなく手を動かしたい」と思っている人。次に OB/OG（すでに 5000 人近く輩出している）、そして加子母の地元の方・施主候補。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 「30年 × 150以上の制作物 × 8大学」という厚みを感じて、「自分の大学のチームに問い合わせてみよう」と思ってほしい。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 地元の大工・山主・製材所・施主がワンセットで学生を受け入れる体制。木を伐るところから建てるところまで同じ谷の中で完結する合宿は日本でここだけです。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「木を育てるように、人を育む」。写真はヒノキの柱を学生が削っているカット、または完成したバス停・ベンチを地元の人が実際に使っている様子。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 木の質感・木漏れ日・材の乾き具合が写る写真を多めに。避けたいのは、チャラい大学サークルっぽさと、逆に重すぎる学会資料っぽさ。両方中間の「現場のプロダクションノート」感が欲しい。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 各大学チームへの問い合わせ導線。塾全体に来るのではなく、自分が所属する（できそうな）大学のチームに飛べること。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 他の建築学生団体は「設計コンペの受賞歴」で自己紹介しがちだけど、うちは「30年の継続」と「地元との共同制作」で語りたい。個人の賞より、集落に残った建物の方が重い。

### Q9. "これがないとウチじゃない"という要素は？
A9. 年度ごとの制作物アーカイブ。1995年以降ずっと何を作ってきたかが全部残っていること。消さない、リストで残す、これは絶対。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 10年は保ってほしい。組織が年次制なのでデザイン改修に毎年工数を取れない。アーカイブ運用だけで持つ構造に。
