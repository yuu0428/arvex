# HATAFURI
- URL: https://recruit.cocolomachi.co.jp/
- 参考カテゴリ: A (地域活性化・メディア系 / キャリア)

## 観察したデザイン特徴
- カード型のグリッドレイアウト、記事プレビューは画像優位
- ナビは「インタビュー / コラム / アンケート / 座談会」のカテゴリ軸
- ミニマルな配色、写真を主役にするために白背景を多用
- タグラインが画面上部に大きく置かれる：「あなたの未来に、ローカルという選択肢を」
- ひたちなかBRIDGEプロジェクトなど**実参加できる案件**がHP上で目立つ位置に固定

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 地方で働くことを選択肢に入れたい学生のためのキャリアメディアです。記事を読ませるだけで終わらせず、ひたちなかBRIDGEのような実プロジェクトへ接続する「読む→参加する」の両輪が本業です。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 東京の大学に通う地方出身の大学3年生。就活で地元に戻るか迷い始めたタイミングで「ローカルで働く＝妥協」というイメージを壊したい。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 「ローカルは退屈じゃない、自分が関われる余地がある」と感じて、インターンに応募するか、少なくともメルマガに登録してくれること。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. ひたちなかBRIDGEプロジェクト。商品開発・メディア発信・まちづくりの現場に学生が入る場を、読者ではなく参加者として用意できるのはウチだけ。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「あなたの未来に、ローカルという選択肢を」。一枚はひたちなかBRIDGEの現場で学生と地元の方が笑っている写真。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 写真は当事者の顔が主役。素材写真の田園風景は避けたい。「ほのぼの田舎」ではなく「手を動かす現場」の質感。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. インターン応募と問い合わせ。記事からスムーズに応募フォームへ流す導線。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 地方移住メディアは"情報発信"で止まりがち。ウチは**リクルートドメイン（recruit.cocolomachi）**に置いている通り、採用・応募が明確なゴール。

### Q9. "これがないとウチじゃない"という要素は？
A9. 座談会コンテンツ。インタビューだけでなく複数人の"本音の空気"を残す形式が芯。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 3〜5年。記事資産は積み上がるので、フレームは長く使う前提で作る。
