# AGESTOCK実行委員会
- URL: http://www.agestock.jp/
- 参考カテゴリ: D（イベント系） / E（メディア混合）

## 観察したデザイン特徴
- 2006 年発足、首都圏の学生団体代表陣が集まる"学生団体の上位互換"的ポジション
- 公式サイトは WEB MAGAZINE / 学祭 JACK / NAMA / CROSTAGE など大量のサブブランドをハブ化
- FRUITS ZIPPER / Da-iCE 級のアーティストを早稲田戸山アリーナに呼び込める規模感
- ロゴ・ニュース・学祭 JACK のアーティストサムネで"芸能系制作会社"に寄せたトーン

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. 2006 年発足、首都圏の学生団体代表陣が集まる企画集団。学祭にアーティストを呼ぶ「学祭 JACK」、学生音楽コンテスト「Next Age Music Award（NAMA）」、WEB マガジン運営の 3 本柱。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 4 層。①学祭 JACK を見に来る一般学生 ②NAMA に応募する学生アーティスト ③協賛・広告出稿の企業 ④AGESTOCK に加入したい新歓対象。事業部ごとに入口を分けたい。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. 興味のある事業（JACK / NAMA / Web Magazine）の詳細ページに必ず 1 クリックで遷移させる。ハブ＝玄関としての仕事が HP の役目。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. FRUITS ZIPPER や Da-iCE クラスを、学生主催で早稲田戸山キャンパスのアリーナに呼んだこと。学生規模のイベントとしては最大級という事実。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 学祭 JACK のアーティスト写真を敷き詰めたヒーロー。「学生が、芸能を動かす。」のような言い切り。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. 芸能プロダクション寄りのシャープさ。学生団体っぽい手作り感は避けたい。協賛企業営業でも恥ずかしくない水準で。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. 新歓期は「加入申込」、コンテスト期は「NAMA 応募」、学祭期は「学祭 JACK 詳細」。ヒーローのボタンだけ季節で差し替える運用。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 単一イベント団体ではなく、事業会社のような"ポートフォリオ"構造で見せること。サブブランドそれぞれに独立 LP を持たせる。

### Q9. "これがないとウチじゃない"という要素は？
A9. 学祭 JACK / NAMA / WEB MAGAZINE の 3 ブランドロゴ並列と、過去出演アーティストの名前ラインナップ。この「実績の厚み」が全て。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 骨格は 5 年級。各事業 LP は年次で差し替え。20 周年に向けて使い続けたい前提。
