# 学生国際協力団体 SIVIO
- URL: https://www.sivio.org/
- 参考カテゴリ: B (国際・ボランティア) / ラオス学校支援

## 観察したデザイン特徴
- 白背景に写真の自然色を乗せるミニマル構成、全体的に軽い
- 日本語はゴシック本文、見出しに明朝を混ぜて「学びと発見」という理想主義的なトーン
- 縦スクロールに、ラオス現地の学校建設・子どもたちとの交流カットを左右交互に配置
- 創設者の言葉 → 活動 → スタディツアー → SNS の順で、代表の顔が前面に出る
- CTA は「Subscribe Form（メルマガ）」「SNS（IG/Twitter）」と、まずは関係を続けるタイプ

## デザイナーからのヒアリング（逆算）

### Q1. この団体は、一言で言うと何をしている団体ですか？
A1. ラオスで学校建設と教育支援をしている学生団体です。年1回メンバーが実際に現地に渡って、校舎を建てたり子どもと交流したり、日本ではミーティングと街頭募金で活動資金を集めています。

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？
A2. 新歓の大学1年生、特に「途上国に興味はあるけど何をすればいいか分からない」女子学生が多い（実際メンバーも女子比率が高い想定）。次に街頭募金で渡したチラシから流入する社会人。

### Q3. 読者が読み終えた時、どうなっていてほしいですか？
A3. スタディツアーが「観光じゃなくて、自分が建てた教室を見に行く行為」だと理解して、次回募集に申し込んでほしい。

### Q4. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？
A4. 募金→設計→渡航→建設→引渡しまでを学生の手で完結させていること。大手NGOに丸投げじゃなく、自分で現地に行って自分で建てる、その手触りの濃さ。

### Q5. HPの"顔"に置きたい一言・一枚は？
A5. 「学びと発見」。写真はラオスの子どもが新しい教室で黒板を指差している瞬間、あるいは学生メンバーが工事現場で土を運んでいる後ろ姿。

### Q6. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？
A6. ラオスの土色・空の青・子どもの笑顔をそのまま使う自然色写真。避けたいのは、貧困を強調する暗い写真、プロカメラマン撮影の整いすぎた広告写真。学生が自分で撮った生写真の方が強い。

### Q7. HPの一番大事な行動喚起（CTA）は何ですか？
A7. まずはメルマガ登録と SNS フォロー。いきなり寄付じゃなくて、関係を継続してからスタディツアー募集に繋ぐ二段階。

### Q8. 他の似た団体のHPと比較して、何を違わせたいですか？
A8. 「世界の教育格差」を数字で訴えるタイプの国際協力サイトとは逆に、ラオスという一国に絞って深掘りする姿勢。広く浅くではなく、狭く深く。

### Q9. "これがないとウチじゃない"という要素は？
A9. 創設者の言葉セクション。代表が変わってもその歴代メッセージを積み重ねて残す構造。あと、年に一度のスタディツアーのログ。

### Q10. HPの寿命はどれくらいを想定していますか？
A10. 5年くらい。学生団体なので毎年代替わりするけど、デザイン自体は引き継ぎしやすいシンプル構造で長持ちさせたい。
