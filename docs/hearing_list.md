# arvex ヒアリングリスト（HP 作成用）

50 件の逆算インタビュー (`docs/reverse_interviews/`) から抽出した、実用的な質問集。

## このリストの使い方

- 各質問には **「意図」**（なぜ聞くか）と **「良い回答の目印」**（使える回答の見分け方）を併記
- 回答が弱かった時の **「掘り下げプローブ」** も用意
- 各質問が **HP のどの要素** に反映されるかを明示
- Interview agent (main agent) の prompt に埋め込んで、質問の質を担保する

## Rule of thumb

- 回答が「社会課題に取り組んでいる」「多様な活動をしている」等の**抽象語**で返ってきたら弱い。必ずプローブで具体を取りに行く
- 数字・固有名詞・日付・引用・エピソードが含まれる回答 = **強い**（そのまま HP に使える）
- 「素材にない」「まだ決まってない」は**尊重**。作り込まない、抽象化か削除
- ヒアリングは **4-6 ラウンド**が適量（多すぎると発散、少なすぎると浅い）

## ブロック 1: 団体の核（Identity）

### Q1. この団体は、一言で言うと何をしている団体ですか？

- **意図**: 最初のフィルター。団体の自己定義を 1 文で聞く。ここで抽象に逃げる団体は素材が薄い
- **HP への反映**: Hero の subtitle、Nav の `about` ラベル、meta description
- **良い回答の目印**: 動詞が 1-2 個入る「◯◯を△△する団体」。固有名詞（地域、対象、手法）が入る
- **弱い回答 → プローブ**:
  - 「社会貢献する」「活動する」→ 「具体的にどんな活動を週何回？」
  - 「若者に◯◯」→ 「何歳の、どこに住んでる若者ですか？」

### Q2. このHPを誰に一番届けたいですか？その読者の具体像は？

- **意図**: 読者ペルソナの仕分け。「万人に届けたい」と言う団体は設計が散漫になる
- **HP への反映**: コピーのトーン、CTA の設計、情報配分（採用優先 vs 寄付優先 vs 参加優先）
- **良い回答の目印**: 年齢・職業・状況が具体（「30-50 代、教育関心の中間層」「理工系 2-3 年生の女子学生」）。主 + 副の層が分かれている
- **弱い回答 → プローブ**:
  - 「みんな」→ 「もし 1 人だけ選ぶなら？」
  - 年齢だけ → 「その人は今どんな悩みを持って検索してる？」

### Q3. 活動の中で「これは私たちにしかできない」と胸を張れる一つは何ですか？

- **意図**: 独自性の抽出。団体の MOAT。ここが空白な団体は、まだ独自性が整理できてない
- **HP への反映**: Hero のメッセージ、差別化コピー、最重要セクション
- **良い回答の目印**: 自分たちで作った造語 / 概念（「ナナメの関係」「未来は、つくれる。」）、長期継続（「20 年以上」）、数字（「40 社以上」「300 人のライター」）
- **弱い回答 → プローブ**:
  - 「他には無い」→ 「具体的にどういう場面でそれが効きましたか？」
  - 「メンバーが熱い」→ 「その熱さが具体的にどんな形で活動に出てますか？」

## ブロック 2: HP が果たす役割（Purpose）

### Q4. 読者が読み終えた時、どうなっていてほしいですか？

- **意図**: HP のゴール設定。感情ゴールと行動ゴールの両方を確認
- **HP への反映**: 全体のテンポ、締めの構成、CTA の強度
- **良い回答の目印**: 感情（「腹落ちする」「勇気が出る」）+ 行動（「フォーム開く」「寄付する」「DM する」）のセット
- **弱い回答 → プローブ**:
  - 「理解してほしい」→ 「理解した後、何をしてほしい？」
  - 「応援してほしい」→ 「応援の具体的な形は？寄付？SNS フォロー？参加？」

### Q5. HPの一番大事な行動喚起（CTA）は何ですか？主 CTA は 1 つに絞るなら？

- **意図**: CTA の数と優先順位。複数 CTA は分散して全てが弱くなる
- **HP への反映**: Hero の CTA ボタン、ページ全体に何度 CTA を置くか、色の強調
- **良い回答の目印**: 1 つに絞られている。何のページ（フォーム / 寄付 / 採用）に飛ばすかが明確
- **弱い回答 → プローブ**:
  - 「全部大事」→ 「もしランディングページで 1 つだけボタン置くなら？」
  - 「お問い合わせ」→ 「どんな用件の問い合わせを期待してる？」

### Q6. 副 CTA / 段階的な導線として置きたいものは？

- **意図**: 主 CTA に踏み切れない読者の受け皿
- **HP への反映**: セカンダリボタン、Footer のリンク構成、段階的導線
- **良い回答の目印**: note を読む / IG を見る / メルマガ登録 等、**低コミットメントの行動**が並ぶ
- **弱い回答 → プローブ**:
  - 「特に無い」→ 「読者が『まだ申し込むには早い』と感じた時の選択肢は？」

## ブロック 3: コンテンツの芯（Content Anchors）

### Q7. HPの"顔"に置きたい一言・一枚は？

- **意図**: Hero の決定。団体が自分で言えないなら、Claude が素材から抽出するのは難しい
- **HP への反映**: Hero のコピーと画像、ファーストビュー
- **良い回答の目印**: 具体的な引用（「未来は、つくれる。」「誰かがやるだろう、では変わらない。」）+ 写真の場面指定（「10 代が真剣に取り組んでる表情」「炎天下の祭り準備」）
- **弱い回答 → プローブ**:
  - 「まだ決まってない」→ 「過去の投稿で一番『これウチらしい』と思った言葉は？」
  - 「ロゴで」→ 「ロゴの横に添える 1 行があるなら？」

### Q8. "これがないとウチじゃない" という要素は何ですか？

- **意図**: 絶対に外せない要素の特定。**omission test の核**
- **HP への反映**: 確実に含めるセクション、それを落としたら NG の判定
- **良い回答の目印**: 具体的なもの（「ナナメの関係という造語」「企業ロゴ壁」「OB OG の名前」「七夕まつりの写真」）
- **弱い回答 → プローブ**:
  - 「特に無い」→ 「もし HP から 1 項目だけ消すとしたら何が一番嫌？」

### Q9. 最も誇る活動を 1 つ挙げて、その場面・数字・忘れられない一言を教えてください

- **意図**: 活動セクションの核となる具体の抽出
- **HP への反映**: Activities セクションの目玉、Evidence セクション
- **良い回答の目印**: 日付・参加人数・場所・引用が揃う
- **弱い回答 → プローブ**:
  - 「たくさんあります」→ 「直近 3 ヶ月で一番印象に残ってるのは？」
  - 「定期活動」→ 「その中で一番反応が良かった回は？」

## ブロック 4: ビジュアルの方向性（Visual Direction）

### Q10. ビジュアル面で大事にしたい要素は？逆に避けたいイメージは？

- **意図**: 両方向から制約を掘る。「避けたい」は強いシグナル
- **HP への反映**: デザイナー選択、配色、typography、モーション
- **良い回答の目印**: 両方向で具体（「清潔感」「上品さ」「手作り感」vs「かわいそうな子ども的な同情ベース」「ピンク×ハートの女子向けテンプレ」「大人がお膳立てした感」）
- **弱い回答 → プローブ**:
  - 「お任せ」→ 「似てる団体で『自分たちはこうはならない』という HP は？」
  - 「おしゃれに」→ 「おしゃれって例えば？雑誌？ブランド？」

### Q11. 参考にしたい / 似せたいサイトはありますか？逆に「こうはなりたくない」サイトは？

- **意図**: moodboard の確定、避けたい方向の明示
- **HP への反映**: デザイナー選択、参考コンテンツ、インスピ source
- **良い回答の目印**: 具体的な URL / 固有名詞（「カタリバの雰囲気」「Kinfolk 的」「Apple の余白」vs「テンプレの Wix」）
- **弱い回答 → プローブ**:
  - 「特に無い」→ 「日頃よく見てる web サイトで『いいな』と思うのは？」

### Q12. 団体の色・書体・ロゴで、必ず守ってほしいブランド要素は？

- **意図**: 既存のブランド資産の確認
- **HP への反映**: Theme tokens、Nav / Footer のロゴ扱い
- **良い回答の目印**: 色の hex、書体名、ロゴの使い方の決まりが具体
- **弱い回答 → プローブ**:
  - 「特に決まってない」→ 「IG で普段使ってる色は？ロゴの背景は？」

## ブロック 5: 運営の現実（Practical / Operational）

### Q13. HPの寿命と更新頻度はどれくらいを想定していますか？

- **意図**: 永続的な HP か一回きりのキャンペーンページかの判定
- **HP への反映**: 号数 / 季節 marker の可否、時事性コンテンツの扱い、ニュース更新機構
- **良い回答の目印**: 「3-5 年スパンで更新」「イベントごとに手動更新」「年次で大改訂」等の具体
- **弱い回答 → プローブ**:
  - 「長く」→ 「途中で情報を書き換えるのは誰？頻度は？」

### Q14. 既にあるアセットは？ロゴ・写真・文章・旧 HP 等、使えるものを教えてください

- **意図**: 再利用可能な素材の棚卸し
- **HP への反映**: 画像 reuse 優先順位、Codex 生成の必要量
- **良い回答の目印**: 具体的なリスト（「IG に直近 1 年分の活動写真」「ロゴは公式データあり」「紹介文は note の代表記事」）
- **弱い回答 → プローブ**:
  - 「特に」→ 「普段 IG 投稿で使う写真はどこに保存してる？」

### Q15. この HP について、団体内で誰が意思決定しますか？

- **意図**: レビュー時の調整方針
- **HP への反映**: 提案 HP のトーン（意思決定者向け vs メンバー向け）
- **良い回答の目印**: 具体的な人（「代表 1 人」「運営メンバー 3 人の合議」「顧問の先生の承諾も必要」）
- **弱い回答 → プローブ**:
  - 「みんな」→ 「最終 OK を出すのは誰？」

## ブロック 6: 差別化（Differentiation）

### Q16. 同じジャンルで似た団体の HP と比較して、どこを違わせたいですか？

- **意図**: ポジショニング確認
- **HP への反映**: 差別化要素の強調、敢えて違うことをする箇所
- **良い回答の目印**: 比較対象の名前 + 違いの具体（「他の教育 NPO が『子どもの課題』を前に出すのに対し、うちは『可能性』を前に出す」）
- **弱い回答 → プローブ**:
  - 「違う」→ 「参考にする団体の HP を 2-3 個挙げて、具体的にどこが違う？」

### Q17. 外から誤解されがちな点は？ それをこの HP でどう解消したいですか？

- **意図**: ネガティブ想定の先回り
- **HP への反映**: 冒頭 or 専用セクションで誤解解消コピー
- **良い回答の目印**: 具体的な誤解（「大学生限定と思われがちだが社会人も OK」「宗教系じゃないか怪しまれる」「ビジネス臭いと敬遠される」）
- **弱い回答 → プローブ**:
  - 「特に無い」→ 「最近入った新メンバーが入る前に不安だったことは？」

## 付録: Interview agent prompt への組み込み

現状の `INTERVIEWER_SYSTEM_PROMPT` の「質問のルール」セクションに、以下を追記推奨:

```
### 良い質問の条件

- 具体を問う（"貴団体の強みは？" のような抽象質問は禁止）
- 素材から読み取れた固有情報（人名・企画名・引用・日付）に触れる
- 団体の**voice**で答えてもらいやすい質問にする（業界用語で返さないような問い方）
- 1 問につき 1 論点（複合質問は避ける）

### 回答が弱い時のプローブ

- 抽象語が返ってきたら「具体的には？直近の例で？」
- 「決まってない」「素材にない」と返ってきたら尊重、執拗に聞かない
- 感情語 (「熱い」「頑張っている」) が返ってきたら「それが具体的にどんな場面で出るか？」
```

## この list の保守

- 新しい HP 制作で**良い質問 / 悪い質問**が分かったら、該当ブロックに追記
- 実際の contract 成約率と逆算して、どの質問が HP 品質に最も効いたかを**学習データ**として記録
- `docs/reverse_interviews/` に新規団体を追加する度に、この list の質問粒度も見直す
